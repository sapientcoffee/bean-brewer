# ☕ Ubiquitous Context: Specialty Coffee Swarm

## Bounded Domains

### 1. Coffee Mood Matching Domain
The Coffee Mood Matching system translates psychological/work modes into extraction variables:
- **TDS (Total Dissolved Solids)**: The percentage of soluble solids extracted from coffee grounds into the cup.
- **Roast Curve**: Light (high fruit acidity, high caffeine retention), Medium (balanced chocolate/fruit, body), Dark (caramelized sugars, bold roast flavors).
- **Brew Seams**: Decoupled modules handling data dictionary lookups, recipe scaling calculations, and interactive stopwatch countdowns.

### 2. Antigravity Modular Swarm
- **`bean-core`**: Expo master orchestrator, canonical stages, and OKF provenance.
- **`bean-roaster`**: Discovery, cupping questions, and PRDs.
- **`bean-grinder`**: AST decomposition and vertical modernization slicing.
- **`bean-brewer`**: Specification, plan council, promotion, and Group Head TDD.
- **`bean-descale`**: Security testing, killchain trees, and gotcha rule immunity.
